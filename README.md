# magpie-plugins

Custom magpie provider plugins by Ye Zhe.

- `plugins/antseed-magpie-plugin` — AntSeed buyer proxy provider for Magpie
- `plugins/freellmapi-magpie-plugin` — FreeLLMAPI provider for Magpie

Install: `magpie plugin add github:yezhe18/magpie-plugins --path plugins/<name>` (or add the subdirectory spec).
